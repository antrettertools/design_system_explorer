**Spec date:** 2026-04-12  
**Phase:** 3 (full detail spec to follow — this is the Phase 3 outline)

## Design Principle

> The showcase is the primary experience on mobile. The generator is a contextual panel that slides up on demand.

No feature is removed — everything is reorganized around the constraint of a single-column viewport. The desktop design makes no compromises to accommodate mobile; the mobile experience is designed separately from first principles, sharing only the token system and component library.

---

## Breakpoints

| Range | Layout |
|---|---|
| `< 768px` | Mobile — stacked, showcase primary, generator as bottom sheet |
| `768px – 1100px` | Tablet — side-by-side, narrower generator panel |
| `> 1100px` | Desktop — current split-panel layout (default) |
| Min touch target | `44 × 44px` on all interactive elements — WCAG 2.5.5 |

**Implementation:** CSS media queries in `App.module.css` and `SplitPane.module.css`. No JS breakpoint detection needed.

## Phase 3 Work Items (outline — full spec to follow)

### 3.1 — Bottom-Sheet Generator

On mobile, the showcase occupies the full viewport. The generator is accessible via a persistent handle at the bottom of the screen.

**Handle (always visible, 64px):**
- Brand color circle (24px, `background: var(--color-interactive)`)
- Font pair name: "Petrona + Mulish" in small UI text
- Regenerate button (replaces SPACE): circular button, `background: var(--color-interactive)`, shuffle/refresh icon

**Three states:**
- **Collapsed:** Handle only. Showcase fills the screen.
- **Half-open:** Generator shows Zone 1 (colors) only. Showcase still visible above the fold.
- **Full-open:** Generator fills ~85% of screen. Showcase peeks 15% at top as the tap-to-dismiss target.

**Gestures:**
- Swipe up on handle → half-open → full-open
- Swipe down → dismiss to collapsed
- Tap the 15% showcase peek → dismiss to collapsed

**Implementation approach:**
- Replace current mobile `showMobilePreview` / `hideMobilePreview` toggle with a three-state bottom sheet
- Sheet state: `'collapsed' | 'half' | 'full'` — local state or new UI store key
- CSS `transform: translateY(...)` for sheet position, spring animation
- The existing mobile-only buttons in `GeneratorFooter.tsx` (`previewBtn`, `generateMobile`) are removed in favour of the handle

### 3.2 — Mobile Detail Mode

Full-screen experience. Bottom navigation pattern.

**Bottom nav (5 tabs):**
- Colors · Type · Spacing · Components · Export
- Icons + labels (same Lucide icons as desktop tab bar)
- Effects tab: accessible via swipe or "More" overflow
- `position: fixed; bottom: 0` — above system nav bar

**Per-tab adaptations:**

| Tab | Mobile-specific behaviour |
|---|---|
| Colors — shade scales | Horizontally scrollable swipe carousel, not a clipping horizontal row |
| Typography — font browser | Full-screen bottom sheet (not slide-in panel). 2-column paired specimen grid. |
| Effects — shadow sliders | Vertical sliders or `+`/`−` numeric inputs. No horizontal sliders (hard to control on touch). |
| Components — token tables | Horizontally scrollable. First column (property name) pinned. No overflow clipping. |
| Export | Full-screen bottom sheet with large-tap-target format cards |
| Showcase | Full-screen template view (same as the main showcase, accessible directly from bottom nav) |

### 3.3 — What Carries Over Unchanged to Mobile

- Lock toggle mechanic — single tap locks/unlocks (same as desktop click)
- Shade picker — long-press on swatch (400ms, already implemented in `ColorSwatches.tsx`) reveals strip
- APCA scores and WCAG contrast ratios — displayed identically in smaller containers
- Font pair rendered in actual fonts — no rendering changes
- Meta-theming — mobile generator handle and bottom nav are also styled by active design system tokens (`--color-interactive`, `--radius-full`, etc.)
- Dark mode toggle — present in generator handle or bottom nav as icon button
- All store logic — no store changes for mobile

### 3.4 — Template Picker on Mobile

The browser chrome frame in `LivePreview` (spec `04-SHOWCASE`) is present on mobile but collapsed: show only the active template name in the URL bar, with a tap to expand the template pill row as a dropdown or bottom sheet row. The chrome frame height remains 36px — pills are revealed on tap, not always visible.

## Acceptance Criteria (Phase 3 — high-level)

- [ ] On mobile (< 768px): showcase fills full viewport on load, generator is not visible until handle is tapped
- [ ] Generator handle is always visible (64px) at bottom of screen, containing brand color circle + font name + regenerate button
- [ ] Bottom sheet animates smoothly between collapsed / half / full states with swipe gesture support
- [ ] All interactive elements in mobile generator and Detail Mode meet 44×44px minimum touch target
- [ ] Detail Mode has bottom navigation with 5 tabs, fixed to bottom of screen
- [ ] Shade scales are horizontally swipeable on mobile
- [ ] Font browser opens as a full-screen sheet on mobile
- [ ] Shadow controls are thumb-friendly (not horizontal sliders)
- [ ] Token tables have pinned first column and horizontal scroll
- [ ] Dark mode toggle is accessible from the generator handle
- [ ] All mobile animations respect `prefers-reduced-motion`
- [ ] Mobile session duration is within 20% of desktop session duration (success metric)
