C
Impact-First (2 phases)
Phase 4A tackles the two highest-impact gaps (editability + color system) together. Phase 4B handles polish + components.
4A
Core Completeness

4B
Polish + Components

Pros

  • Fast to visible impact
  • Only 2 specs
  • Natural split

Cons

  • 4A is still large
  • Less granular review
My recommendation: B (Domain-Split). The editability work (color pickers, effects builders) is technically meaty and benefits from focused review. The color system work (showcase templates, dark mode coverage) is a different skill set — mostly CSS and token design. Keeping them separate makes each session cleaner and lets you validate one domain before the next starts. 4D (UX Polish) can even run as a quick cleanup session at the end.
