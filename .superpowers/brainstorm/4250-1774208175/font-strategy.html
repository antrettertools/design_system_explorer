Option A — Recommended
Body font for chrome · heading font for identity
All buttons, pills, labels use the selected body font. The wordmark + section result names use the heading font. You feel the font pairing throughout the app. With Playfair+Inter it's beautiful. With Bebas+Roboto, the chrome stays readable (body = Roboto) while the wordmark gets personality.
Option B
System font everywhere (current behaviour)
App chrome always uses the OS system font (SF Pro, Segoe UI). The specimen area shows the selected fonts. Safe and predictable — but the chrome feels disconnected from the design system you're building.
