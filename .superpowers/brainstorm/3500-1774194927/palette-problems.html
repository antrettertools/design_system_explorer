What breaks today, and three paths to richer palettes

TODAY: Triadic + 8 slots = repeating garbage
Triadic has only 3 hue offsets. With 8 slots, the code wraps: hues cycle as 0°→120°→240°→0°→120°→240°→… and all colors share the same narrow L/C range (±7% lightness, ±4% chroma). Result: near-identical swatches.

repeat green₂
repeat purple₂
repeat orange₃

Three distinct hues. Eight near-identical colors. No neutrals. No light or dark anchors. No variation in saturation.

Three strategies for richer generation

A

Slot Roles — Vivid + Tint + Shade

Extra slots beyond the harmony count get assigned as tint (lighter, lower C) or shade (darker) of an existing hue. Each hue gets 1 vivid + 1 tint + optionally 1 shade.

tintorange tint
vividorange
shadeorn shade
tintgreen tint
vividgreen
shadegrn shade
tintpurp tint
vividpurple

+ Each harmony hue gets its own tint/shade. More variety, but no neutral anchors.

B

Neutral Anchors — Light + Dark Always Present

Reserve 2 slots always for a near-white (L≈0.96) and near-black (L≈0.14). Remaining slots get the harmony hues + muted variants. Gives every palette a usable light/dark base.

anchornear-white
vividorange
vividgreen
vividpurple
mutedorn muted
mutedgrn muted
mutedpurp muted
anchornear-black

+ Every palette instantly usable for UI (text, bg, surfaces). But 2 slots "spent" on neutrals.

C

Enriched Harmony — Wide L/C + Hue Jitter

Keep the harmony hue structure but dramatically widen the L (0.20–0.90) and C (0.02–0.25) sampling ranges. Add small random hue jitter (±8°) per slot. Extra slots pick from a fresh hue derived from the model.

L=0.95near-wht
L=0.68orange
L=0.68green
L=0.62purple
L=0.30orn dark
L=0.88grn pale
L=0.28purp dark
L=0.14near-blk

+ Most variety. Hue stays "in family" but L/C spread creates radically different moods per slot.

Also needed: model override UI
Currently the harmony mode (triadic, analogous, etc.) shows only when slots are locked. We need a persistent mode selector — either a pill row or dropdown — so you can pin or force the mode before generating.
