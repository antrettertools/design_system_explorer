Two-Tier Harmony System — Full Concept

Primary mode gives the character. Secondary mode adds the surprise. Slot types fill the count.

The core idea: Every palette has a primary mode (e.g. triadic) that defines the main hues, and a secondary mode (auto-paired or user-chosen) that contributes 1–2 accent hues from a different harmonic angle. Remaining slots fill from a priority queue: tints → shades → additional neutrals.
Tier 1 — Primary mode
e.g. Triadic
Generates 3 anchor hues at 0°, 120°, 240° from base. Wide L/C sampling (L 0.30–0.75, C 0.14–0.26). These are the palette's "character" colors.
+
Tier 2 — Secondary mode (auto-paired)
e.g. Split-complement of brand hue
Generates 1–2 hues from a different harmonic rule applied to the brand hue. Low-mid C so they feel like accents, not rivals. Auto-pairing table: triadic→split-comp, analogous→complement, comp→analogous, mono→accent.
+
Slot fill — priority queue
Neutrals → Tints → Shades
When N > primary + secondary hues, fill remaining slots: near-white first, then tint of brand, then near-black, then additional tints of secondary hues.
