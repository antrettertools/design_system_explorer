What the code looks like
generatePalette() now picks a recipe instead of a model. Each recipe is
{ primaryMode, secondaryMode, fillOrder: SlotType[] }.
A slot type encodes hue source + depth level: P1-vivid, S1-pale, neutral-dark, etc.
The fill order is trimmed to count slots from the front. Locked slots skip their position.
activeRecipe replaces activeModel in the store. The pill reads from it.
Clicking a pill item sets pinnedRecipe — if set, generate() always uses it.
