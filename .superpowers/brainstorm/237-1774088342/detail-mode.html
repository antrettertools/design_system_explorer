Detail Mode — Tab Structure

Same 50/50 split. Left panel becomes a tabbed editor. Right panel gets template switcher. Continuous flow — no state lost from generator.

Tab overview — what lives where

Colors Phase 1
  • ● Shade scale per color (9 steps)
  • ● Semantic role assignments
  • ● Contrast grid (WCAG AA/AAA)
  • ● Dark mode derived palette
  • ● Manual hex/OKLCH override
  • ● Add / remove / reorder colors
Typography Phase 1
  • ● Full font browser (GF + Fontshare)
  • ● Scale ratio picker (1.25–1.5)
  • ● Per-step size / weight / lh override
  • ● Live type specimen
  • ● Readability score (APCA)
  • ● Lock heading / body independently
Spacing Phase 2
  • ● Base unit + scale (4pt / 8pt grid)
  • ● Named steps (xs → 3xl)
  • ● Border radius scale
  • ● Breakpoints
  • ● Z-index layers
  • ● Visual spacing ruler preview
Shadows Phase 2
  • ● Elevation presets (sm/md/lg/xl)
  • ● Color-tinted shadows from brand
  • ● Custom shadow builder
  • ● Inner shadow support
  • ● Preview on card component
Showcase Phase 1
  • ● Switchable templates (Landing / Dashboard / Blog)
  • ● System view (swatches + type specimen)
  • ● Light / dark mode toggle
  • ● Full-screen expand
  • ● Share URL
Export Phase 1
  • ● CSS custom properties
  • ● Tailwind config (v3 + v4)
  • ● W3C design token JSON
  • ● SCSS variables
  • ● Copy to clipboard / download
  • ● Naming convention picker
