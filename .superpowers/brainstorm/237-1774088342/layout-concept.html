What's the core layout feel for v3?

This is the foundational UX decision — how the generator and live preview relate to each other

Generator

A — Equal Split (50/50)

Generator panel left, live preview right. Both get equal real estate. Focused, dual-pane workflow — like a code editor + preview.

Colors

B — Preview-First (30/70)

Compact controls sidebar, large preview dominates. The live website is the star. Controls feel lightweight and tool-like.

Aa

C — Immersive Preview + Floating Toolbar

Full-screen live preview. Color/font palette floats as a compact toolbar overlay — like Coolors. Maximally immersive, tool feels invisible.
